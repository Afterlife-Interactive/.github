# Afterlife Interactive

Afterlife Interactive LLC publishes Ramsgate Reborn, a free, fan-run server for Dauntless, the co-op monster-hunting game. It lets players hunt Behemoths together again after the official servers closed.

## Ramsgate Reborn

- Website: [afterlifeinteractive.com](https://afterlifeinteractive.com/ramsgate-reborn.html)
- Help: [support site](https://support.afterlifeinteractive.com/)

Ramsgate Reborn is unofficial. It is not made, endorsed or supported by Phoenix Labs, Epic Games, Forte Labs or anyone who owns or owned Dauntless.

It started from Mystic Paradox, an earlier community project by Pranav Karande and contributors, which in turn comes from Undaunted by gwog. Both are AGPL-3.0 and so is Ramsgate Reborn.

## Dauntless Revived

Dauntless Revived is a separate fan server for an older game version. If you played there, the Ramsgate Reborn launcher can move that progress to your Ramsgate Reborn account.
